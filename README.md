# نظام إدارة تكاليف المصنع (Factory Production Cost Management System)

تطبيق ويب متكامل باللغة العربية مع دعم كامل لاتجاه اليمين إلى اليسار (RTL)، مبني باستخدام **Laravel 11 / PHP 8.3 / MySQL**، كبديل احترافي وآمن لورقة الإدخال اليومي في مصنف إكسل `تكاليف_المصنع_مُصحح.xlsx`. التطبيق جاهز ومجهز للنشر المباشر على استضافة **Hostinger المشتركة**.

---

## 🌟 مميزات النظام

- **واجهة مستخدم عربية بالكامل (RTL)**: مبنية باستخدام خط **Tajawal** بتصميم عصري وهادئ ومريح للعين، متوافق مع كافة أحجام الشاشات.
- **تطبيق دقيق لكافة معادلات الإكسل**: احتساب بنود التكاليف الـ 16 آلياً وفقاً لقواعد التسعير المعيارية ونوع التخزين وشركات وأسعار الأقمشة.
- **حفظ السجلات التاريخية (Historical Snapshot)**: تخزين أسعار المعايير والوحدات المطبقة لحظة حفظ التقرير لضمان عدم تأثر السجلات المحاسبية السابقة عند تعديل الأسعار مستقبلاً.
- **شاشة إدخال يومي مرنة (الإدخال اليومي)**:
  - جدول مريح لسطح المكتب مع تثبيت الترويسة وأعمدة الأكواد (Sticky Columns & Headers).
  - بطاقات سريعة ومتجاوبة لشاشات الهواتف المحمولة تمنع التمرير الأفقي المزعج.
  - شريط إجمالي عائم ومباشر (Live Preview).
  - منع التكرار والتحقق من التواريخ السابقة مع توفير رابط فوري لتعديل السجل الحالي.
  - تحذير عند مغادرة الصفحة مع وجود تعديلات غير محفوظة.
  - منع الإرسال المزدوج مع حالة تحميل واضحة.
- **شاشة سجلات شاملة (السجلات اليومية)**:
  - تصفية متقدمة حسب تاريخ محدد أو نطاق زمني (من تاريخ / إلى تاريخ).
  - ترقيم صفحات (Pagination) وفرز تلقائي يبدأ بالأحدث.
  - تفاصيل محاسبية دقيقة وإمكانية الطباعة، التعديل، والحذف الآمن (Soft Deletes).
- **أمان عالي واحترافي**:
  - تسجيل دخول آمن مع تشفير كلمات المرور.
  - حماية كاملة ضد هجمات CSRF و SQL Injection و Mass Assignment.
  - تحديد معدل محاولات تسجيل الدخول (Rate Limiting) لمنع الهجمات التخمينية.
- **جاهز للنشر على Hostinger Shared Hosting**: بدون أي حاجة لـ Node.js في بيئة الإنتاج.

## 🚀 تشغيل المشروع محلياً

1. التأكد من وجود PHP 8.2+ و Composer.
2. تثبيت الحزم (إذا تم نقل المشروع):
   ```bash
   composer install
   ```
3. إعداد ملف البيئة:
   ```bash
   cp .env.example .env
   php artisan key:generate
   ```
4. تشغيل التهجير وبذر البيانات:
   ```bash
   php artisan migrate:fresh --seed
   ```
5. تشغيل خادم التطوير:
   ```bash
   php artisan serve
   ```
