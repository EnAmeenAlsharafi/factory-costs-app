# Stage 3.5 — UI/UX Shell Refactor

## النطاق

تعيد هذه المرحلة تنظيم طبقة العرض فقط لنظام مصنع مفروشات سدير. لم تتغير قاعدة البيانات أو النماذج أو العلاقات أو الـseeders أو مسارات العمل أو معاني الصلاحيات، ولم تُنفذ أي وحدة من Stage 4.

## الهيكل المشترك

يتكون التطبيق المصادق عليه من:

1. `app-layout-wrapper`: حاوية Flex باتجاه RTL.
2. `app-sidebar-column`: عمود مستقل للشريط الجانبي على اليمين.
3. `app-main-column`: مساحة مرنة ذات `min-width: 0` تضم الـheader ثم المحتوى ثم footer.
4. `app-content-container`: حاوية المحتوى الوحيدة، بمسافات تتدرج حسب عرض الشاشة.
5. `partials/page-header`: نمط موحد للعنوان، الوصف، breadcrumb، والإجراء الرئيسي المقيّد بالصلاحية.

هذا الفصل يمنع تداخل sidebar أو header مع المحتوى والجداول من دون استخدام `overflow-x: hidden` على الصفحة كحل تجميلي.

## RTL وSidebar

- المستند عربي ويستخدم `dir="rtl"`، بينما الأكواد والمعرفات والهواتف والأرقام التقنية معزولة باتجاه LTR.
- عرض sidebar هو 272px على سطح المكتب، و248px على الشاشات المتوسطة، و80px عند الطي.
- حالة الطي تحفظ محليًا في المتصفح، وتبقى الأيقونات قابلة للوصول مع عناوين واضحة.
- تحت 768px يتحول sidebar إلى drawer من اليمين بعرض لا يتجاوز 304px، مع overlay وإغلاق بزر واضح أو بالنقر خارج القائمة أو بمفتاح Escape.
- يمنع تمرير جسم الصفحة فقط أثناء فتح drawer على الجوال؛ تمرير القائمة نفسها مستقل وموضعي.

ترتيب الطبقات المعتمد:

- المحتوى: 1
- header المثبت: 1020
- overlay الجوال: 1040
- sidebar/drawer: 1045 حتى يبقى قابلًا للتفاعل فوق الغطاء
- modal: 1060

## الأصول والخطوط

تُجمع الأصول الأساسية عبر Vite:

- Bootstrap 5.3 RTL
- Alpine.js
- Font Awesome
- Cairo بأوزان 400 و500 و600 و700
- CSS الخاص بالنظام في `resources/css/app.css`
- JavaScript الخاص بالـshell في `resources/js/app.js`

أزيلت مراجع Google Fonts وjsDelivr وcdnjs من layout وصفحة الدخول، ولذلك لم تعد مشكلة SRI الخاصة بـBootstrap قادرة على تعطيل التنسيق. لا توجد تبعيات CDN فعالة في صفحات التطبيق أو تسجيل الدخول. صفحة Laravel الافتراضية `welcome.blade.php` تحتوي روابط وثائق خارجية لكنها ليست ضمن shell ولا تُستخدم في المسارات الحالية.

## الأنماط البصرية

- الخط: Cairo محلي، مع fallback إلى Segoe UI ثم Tahoma وArial.
- الخلفية: `#f4f7fb`.
- الأسطح: أبيض، وحدود `#dbe3ee`، ونص أساسي `#172033`.
- اللون المميز: أصفر المصنع `#eab308` مع حالة hover أغمق.
- البطاقات موحدة بحد خفيف، نصف قطر 0.85rem، وظل منخفض.
- جميع عناصر الإدخال 44px على الأقل، مع focus ring واضح عالي التباين.
- الحالات لا تعتمد على اللون وحده؛ تستخدم نصًا وأيقونة أو وصفًا صريحًا.

## الجداول والقوائم

- كل جدول في الصفحات المستهدفة موجود داخل `.table-responsive` داخل `.table-factory-wrapper`.
- overflow أفقي محصور في wrapper ولا يمدد الصفحة.
- wrapper قابل للتركيز بلوحة المفاتيح وله اسم وصول، وتظهر على الجوال رسالة واضحة تفيد بإمكانية التمرير الأفقي.
- الحد الأدنى للجداول على الهاتف 680px بدل 800–900px، مع أهداف لمس 44px للإجراءات.
- الأكواد تستخدم `.code-badge` وLTR مع `unicode-bidi: isolate`.
- البحث والمرشحات تستخدم نفس قياسات الحقول والبطاقات، والـpagination يلتف عند ضيق المساحة.
- الخلايا الفارغة تعرض رسالة وأيقونة ونصًا، ولا تعتمد على فراغ بصري فقط.

## النماذج

- الحقول منظمة ضمن شبكة Bootstrap: عمودان على desktop عند الملاءمة وعمود واحد على mobile.
- رسائل التحقق تبقى أسفل الحقول عبر `invalid-feedback` الحالية.
- حقول الهاتف والبريد والأرقام والأكواد تعرض LTR.
- أشرطة الحفظ والإلغاء تصبح sticky داخل النموذج، وتتحول إلى أزرار كاملة العرض على الجوال.
- أسماء الحقول والمسارات وطلبات POST/PUT الحالية لم تتغير.

## مصفوفة الصلاحيات

- تعرض أسماء الوحدات بالعربية وتضع المفتاح التقني كسطر ثانوي LTR.
- زر «تحديد كل صلاحيات المجموعة» يهيئ نفسه من القيم المحفوظة.
- تظهر حالة `indeterminate` عند تحديد جزء من المجموعة.
- يظهر عداد لكل مجموعة وعداد إجمالي حي للصلاحيات المحددة.
- شريط الحفظ responsive وsticky، ولم تتغير قيم الصلاحيات أو ربط الأدوار.

## Dashboard والصلاحيات

- أزيل hero التسويقي ومؤشرات الإنتاج/WIP الصفرية غير المرتبطة بمصدر بيانات.
- تعرض اللوحة فقط أرقام البيانات الأساسية الموجودة فعلًا، وكل بطاقة ورابط داخل `@can` المناسب.
- تختلف الروابط الظاهرة بين Administrator وProduction Manager وCustomer Service وWarehouse Keeper وProduction Worker.
- الوحدات المستقبلية تظهر كشارة «قريبًا» غير قابلة للنقر، وفقط لمن يملك صلاحية الوحدة.
- حسابات الدخول التجريبية محصورة في بيئتي `local` و`testing`.

## الوصول

- أضيفت أسماء عربية لأزرار القائمة والإغلاق وحساب المستخدم والـmodal.
- sidebar وtable regions وdialog موصوفة دلاليًا.
- Escape يغلق drawer والـmodal.
- يراعي CSS إعداد `prefers-reduced-motion`.
- صفحات 403 و404 و500 تستخدم قالبًا عربيًا موحدًا وخفيفًا.

## التحقق المنفذ

- `npm run build`: ناجح، والأصول والخطوط وBootstrap وFont Awesome وAlpine خرجت إلى `public/build`.
- `php artisan view:cache`: ناجح لكل قوالب Blade.
- `php artisan test --compact`: 50 اختبارًا ناجحًا، 199 assertion.
- HTTP محلي: login وdashboard وكل صفحات list/create المطلوبة أعادت 200 للمسؤول.
- صفحات edit/show: users وroles وcustomers وcustomer types وsales channels وunits وdepartments أعادت 200.
- قالب suppliers/edit جُمّع بنجاح، واختبار تحديث المورد ناجح؛ لم يوجد سجل مورد حالي لفحص GET دون إنشاء بيانات.
- الأصول المجمعة CSS/JS أعادت 200، وكل absolute asset host يشير إلى `127.0.0.1:8000` فقط.
- تم فحص الأدوار الخمسة: الصفحة المسموحة أعادت 200، والصفحة الممنوعة أعادت 403، وروابط users/customers/suppliers/departments ظهرت أو غابت وفق الصلاحيات.

تعذر تشغيل أداة المتصفح المرئية داخل بيئة التنفيذ بسبب خطأ ACL قبل إنشاء جلسة المتصفح. لذلك لم يُدّعَ إتمام فحص screenshots أو console أو القياس البصري الفعلي عند 1920 و1440 و1366 و1024 و768 و390px. غُطيت نقاط الانكسار في CSS وفُحصت بنيويًا، لكن يلزم smoke test بصري أخير على هذه المقاسات في متصفح متاح قبل اعتماد الإصدار للإنتاج.
